# Sistema de Almacén - Actividad 2.3 

Aplicación de consola en Java para gestionar el inventario de un almacén.

## Estructura

- `Producto`: nombre y stock de un producto.
- `Inventario`: administra un `ArrayList<Producto>` con las reglas de negocio.
- `Main`: menú de consola.
- `InventarioTest`: pruebas JUnit 5.


## Casos de uso

1. Registrar / Reponer producto
2. Vender producto
3. Ver inventario
4. Ver stock crítico (5 unidades o menoss)
